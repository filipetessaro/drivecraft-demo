# Drivecraft Demo

Windows demo of **Drivecraft**, multiplayer vehicles and traffic for Unreal Engine 5.6 to 5.8: a car, a truck with its
semi-trailer and a motorbike that a player drives without waiting for the server, and traffic with junctions, traffic
lights and lane changes. The demo is the plugin's own example town, packaged as a Shipping build with UE 5.8.

**Download:** DrivecraftDemo_Win64.zip (294 MB), in the [latest release](https://github.com/filipetessaro/drivecraft-demo/releases/latest).
Windows 64-bit, DirectX 12. No engine needed.

Unzip it anywhere and run `DrivecraftDemo.exe`. You start on foot next to two cars, a motorbike and a truck with its
trailer: walk to one and press E.

| Key | On foot | Driving |
|---|---|---|
| WASD + mouse | Walk and look | Throttle, brake (hold S when stopped to back up), steer, look around |
| Space | Jump | Handbrake (held) |
| E | Get in the nearest vehicle | Get out |
| F | | Another seat |
| C | | Chase camera or driver's seat |
| L | | Headlights |
| Left / Right / Down | | Turn signals / hazard lights |
| H | | Horn |
| R | | Back on its wheels after rolling over |
| F1 / F2 | Host / join on this PC | Host / join on this PC |

To drive together, press F1 on one machine to host and F2 in another window on the same PC, or run
`DrivecraftDemo.exe <host's address>` from another machine.

`HOW_TO_RUN.txt` inside the zip has the rest: what to try in the town, the dirt and ice yards, the traffic lights.
